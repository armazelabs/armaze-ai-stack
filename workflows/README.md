# Workflows

Multi-step orchestrations that compose skills and agents into a repeatable process — e.g. "spec → plan → implement → review → release notes".

One directory per workflow with a `README.md` describing the steps, the inputs, which skills/agents each step uses, and the hand-offs between them. Scripts that drive a workflow live alongside it.

`aistack add` does not install workflows yet; copy them by hand for now.
