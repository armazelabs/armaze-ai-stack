# Frontend Design

Helps Claude pick a clear aesthetic direction before it builds UI, so new screens and pages look designed rather than templated.

## What You Get

- The `frontend-design:frontend-design` skill, which Claude uses on its own when it builds or reshapes a frontend

## How It Installs

`aistack add frontend-design` enables it in the project's `.claude/settings.json` (`--global` enables it for all your projects). Claude Code installs it for everyone who opens the project and keeps it up to date. Claude Code only.
