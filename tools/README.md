# Tools

Standalone helpers that skills, agents and workflows can call: zsh/Python/Node scripts, small CLIs, and MCP servers.

One directory per tool with its own `README.md` covering what it does, how to run it, and what it needs (runtimes, API keys, environment variables). Never commit secrets — document the variable name and read it from the environment.

`aistack add` does not install tools yet; copy them by hand for now.
